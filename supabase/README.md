# เซิร์ฟเวอร์ Supabase (ช่วง CBT)

## ตั้งค่าครั้งแรก
1. Supabase → **SQL Editor** → New query → วางทั้งไฟล์ `schema.sql` → **Run**
2. **Authentication → Sign In / Providers → Email** → ปิด **Confirm email** → Save
   (เกมใช้ชื่อผู้ใช้ ระบบแปลงเป็นอีเมลภายใน `ชื่อ@siamduel.game` ซึ่งรับอีเมลยืนยันไม่ได้)
3. เปิดเกม สมัครบัญชีของแอดมิน แล้วรันใน SQL Editor:
   ```sql
   insert into public.admins select id from auth.users where email = 'ชื่อผู้ใช้@siamduel.game';
   ```
4. รัน `002_tutorial.sql` (รางวัลบทเรียน) ใน SQL Editor ครั้งเดียว — ถ้ารัน `schema.sql` เวอร์ชันใหม่ทั้งไฟล์แล้ว ไม่ต้องรันไฟล์นี้
5. เปิดหลังบ้านในเกมด้วย `?admin=1` หรือ `Ctrl+Shift+A`

## รีเซตข้อมูล CBT
รัน `schema.sql` ซ้ำ: โปรไฟล์ การ์ด ตลาด ข่าว ถูกล้าง บัญชีล็อกอินยังอยู่ (โปรไฟล์ใหม่สร้างให้อัตโนมัติ แต่ต้องเพิ่มแอดมินใหม่ตามข้อ 3)
ถ้าต้องการลบบัญชีด้วย: Authentication → Users → ลบ

## สิ่งที่อยู่บนเซิร์ฟเวอร์
| ส่วน | การทำงาน |
| --- | --- |
| ล็อกอิน | Supabase Auth, ชื่อผู้ใช้ a-z 0-9 _ ยาว 3–20 ตัว |
| โปรไฟล์ | ผู้เล่นแก้ได้เฉพาะ ชื่อ เพศ เด็ค การตั้งค่าผู้นำทาง · โกลด์/แต้มบุญ/จำนวนสุ่ม แก้ได้เฉพาะผ่านฟังก์ชันเซิร์ฟเวอร์ |
| ตู้สุ่ม `gacha_pull` | สุ่มบนเซิร์ฟเวอร์ อัตรา การันตี 200 การ์ดพระเจ้าแบบละ ๓ ใบ (ล็อกแถวกันออกเกิน) |
| ตู้ผู้สรรสร้าง `gacha_event_pull` | ต้องสุ่มครบเกณฑ์ 5,000 โกลด์ 0.5% ได้แล้วปิดรอบอัตโนมัติ |
| ตลาดกลาง `market_list/cancel/buy` | ซื้อขายระหว่างผู้เล่นจริง โอนโกลด์+การ์ดในธุรกรรมเดียว ค่าธรรมเนียม 5% ถูกเผา พ่อค้า NPC เติมของเมื่อเหลือน้อย |
| ข่าว | ตาราง `news` แบบเรียลไทม์ ประกาศการ์ดพระเจ้า/ผู้สรรสร้าง และการซื้อขาย |
| บทเรียน `tutorial_claim` | รับรางวัลบทเรียนแต่ละบทได้ครั้งเดียว (โกลด์ หรือการ์ดหายาก/มหากาพย์สุ่ม) |
| แอดมิน | `admin_set_event`, `admin_add_gold`, `admin_seed_market` ตรวจสิทธิ์จากตาราง `admins` |

คีย์ในเกม (`index.html`) เป็น publishable key ซึ่งเปิดเผยได้ ห้ามใส่ secret key ในโค้ดเด็ดขาด
