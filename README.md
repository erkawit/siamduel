# สยามมินทร์ดูเอล (Siam Duel)

เกมการ์ดสะสมและดวลแนวไทยดาร์กแฟนตาซี: เทพ ผี อสูร สัตว์หิมพานต์ วรรณคดี และผู้ปกครองไทย การ์ด 100 ใบ 7 ระดับ (ธรรมดา → ผู้สรรสร้าง)

## ช่วงทดสอบปิด (CBT)
- เล่นผ่านเบราว์เซอร์ที่ลิงก์ GitHub Pages ของ repo นี้
- ข้อมูลผู้ทดสอบ (บัญชี โกลด์ การ์ด เด็ค) เก็บในเบราว์เซอร์และ **จะถูกรีเซตเมื่อสิ้นสุดการทดสอบ**
- รีเซตทุกคนพร้อมกัน: แก้ `CBT_ROUND` ใน `index.html` เป็นเลขถัดไปแล้วอัปขึ้น
- ผู้ทดสอบแจ้งบั๊ก/ความเห็นได้จากปุ่ม "CBT · แจ้งปัญหา" ในเกม (เปิดเป็น Issue ใน repo นี้)

## ตัวต้นแบบ (Prototype)
เปิด `index.html` ในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้ง

- หน้าโหลด → ล็อกอิน/สมัคร (การ์ดตัวอย่างลอยและเอียงได้) → เลือกตัวละครชาย/หญิง → หน้าแรก
- ห้องพักส่วนตัว: เด็ค 3 เซ็ต ผูกโหมดการดวลได้ ตรวจกติกาอัตโนมัติ
- ตู้สุ่มกาชา: อัตราจริง การันตีตำนาน 200 ครั้ง การ์ดพระเจ้าแบบละ ๓ ใบ พร้อมป๊อปอัปอธิบายกติกา
- ตู้ผู้สรรสร้าง (Event): แสดงเมื่อเปิดจากหลังบ้านจำลองเท่านั้น (`Ctrl+Shift+A` หรือ `index.html?admin=1`)
- คลังการ์ด ดูการ์ดขยายพร้อมเอฟเฟกต์ระยิบระยับตามระดับ
- หอกิลด์ (หน้าตัวอย่าง)

ข้อจำกัด: บัญชี โกลด์ และการ์ดในตัวต้นแบบเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น ระบบเข้ารหัส ใบรับรองการ์ด ตลาดกลาง กิลด์ และดวลออนไลน์อยู่ในขั้นสร้างจริง (ดูเอกสาร)

## โครงสร้าง
| โฟลเดอร์ | เนื้อหา |
| --- | --- |
| `game_assets/` | ภาพการ์ด 100 ใบ + โทเคน 11 ใบ, กรอบ 7 ระดับ, หลังการ์ด, ไอคอนธาตุ/ประเภท, `manifest.json` (ตำแหน่งช่องภาพแต่ละกรอบ) |
| `ui_art_web/` | ฉาก ปุ่ม ไอคอนเมนู เอฟเฟกต์ตู้สุ่ม กระดานชนวน |
| `characters/` | ตัวละครผู้เล่นพื้นใส หันซ้าย/ขวา เต็มตัว/ครึ่งตัว |
| `data/siam_duel_cards.json` | ข้อมูลการ์ดทั้งหมด (ค่าพลัง ความสามารถ ability_code ระดับ จำนวนจำกัด) |
| `docs/` | กติกา R1–R17, เทสต์ T01–T30, เศรษฐกิจโกลด์/ตู้สุ่ม, ระบบสอนเล่น/กติกาพิเศษ, หน้าดวล/ห้องพัก/2v2/P2P/กิลด์/AI |
| `docs/prompts/` | Prompt สร้างภาพการ์ด ตัวละคร กราฟิก UI และฉบับสะสม |
| `tools/` | สคริปต์ Python: ประกอบการ์ด, ลบพื้นเขียว/ดำ, ตรวจการ์ด, สร้างชุดไฟล์เกม |

## ขั้นต่อไป
1. หน้าดวลกระดานชนวนกับ AI (เอนจินดวลตามกติกา + เทสต์ T01–T30)
2. ระบบสอนเล่นแบบจับมือ 8 บท
3. โปรเจกต์จริง Next.js + Supabase: ล็อกอิน ตู้นิรภัยการ์ด ใบรับรอง ตลาดกลาง P2P ออนไลน์ กิลด์
