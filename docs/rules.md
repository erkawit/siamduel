# สยามินทร์ดุเอล (Siam Duel) — กฎการเล่นฉบับเอนจิน

เอกสารนี้คือแหล่งความจริงเดียวของกฎ ถ้าโค้ดกับเอกสารขัดกัน ให้ทำตามเอกสาร ทุกกฎมีเลข R ไว้อ้างอิงเวลาแจ้งบั๊ก

## R1 องค์ประกอบ
- R1.1 ผู้เล่น 2 คน แต่ละคนมี: ดวงชะตา (HP ผู้เล่น) เริ่ม 30 สูงสุด 30, เด็ค, มือ, สนามยูนิต 5 ช่อง (ช่อง 0–4 ซ้ายไปขวา), ช่องกับดัก/ของขลัง 2 ช่อง, สุสาน (เรียงตามลำดับที่ตาย), เขตส่งวิญญาณ (การ์ดที่ออกจากเกมถาวร)
- R1.2 พลังงานชื่อ "อาคม" (ใช้ได้เทิร์นนี้) และ "บารมี" (สะสม สูงสุด 3 ใช้ได้กับคาถา/กับดัก/ของขลังเท่านั้น จ่ายบารมีก่อนอาคมเสมอ ถ้าผู้เล่นไม่เลือกเอง)
- R1.3 ชนิดการ์ด: ยูนิต (มี ATK/HP), คาถา (ใช้แล้วลงสุสาน), กับดัก (วางคว่ำ ทำงานเมื่อเงื่อนไขเกิด แล้วลงสุสาน), ของขลัง (วางหงาย อยู่ถาวร; ของขลังแบบ "ติดยูนิต" ผูกกับยูนิตนั้นและไม่ใช้ช่อง), ของขลัง (สนาม) ใช้ช่องกับดัก/ของขลัง
- R1.4 ค่าบนการ์ด: ระดับ 7 ระดับ (ธรรมดา ทั่วไป หายาก มหากาพย์ ตำนาน พระเจ้า ผู้สรรสร้าง), หมวด, เผ่า (เทพ/มนุษย์/อสูร/หิมพานต์/ผี/อากาศ), ธาตุ (น้ำ/ไฟ/ดิน/ลม/อากาศ), ต้นทุน, ATK, HP, keywords, ability_code
- R1.5 โทเคน = ยูนิตที่เกิดจากเอฟเฟกต์ ไม่อยู่ในเด็ค ตายแล้วหายไปเลย (ไม่ลงสุสาน ชุบชีวิตไม่ได้)

## R2 การจัดเด็ค
- R2.1 เด็ค 30 ใบพอดี
- R2.2 ลิมิตต่อชื่อ: ธรรมดา/ทั่วไป 3, หายาก/มหากาพย์ 2, ตำนาน/พระเจ้า 1, ผู้สรรสร้าง 1 ใบทั้งระดับ (มีผู้สรรสร้างได้แค่ 1 ใบในเด็ค)
- R2.3 การ์ดระดับตำนาน + พระเจ้า + ผู้สรรสร้าง รวมไม่เกิน 3 ใบ
- R2.4 การ์ดหมวด "เทพเจ้า" + "ผู้ปกครอง" รวมไม่เกิน 3 ใบ
- R2.5 เด็คเริ่มต้นสำหรับผู้เล่นใหม่และ AI มี 4 เด็คสำเร็จรูป (ดู R13)

## R3 เริ่มเกม
- R3.1 สุ่มผู้เล่นแรกด้วย RNG ของเซิร์ฟเวอร์ (seeded)
- R3.2 สับเด็ค ผู้เล่นแรกจั่ว 3 ใบ ผู้เล่นที่สองจั่ว 4 ใบ + ได้การ์ดพิเศษ "เบี้ยหอยเสี่ยงทาย" (คาถา ต้นทุน 0: ได้อาคม +1 เทิร์นนี้)
- R3.3 Mulligan: แต่ละคนเลือกการ์ดในมือที่จะเปลี่ยนได้ครั้งเดียว (0 ถึงทุกใบ) สับกลับเข้าเด็คแล้วจั่วใหม่เท่าจำนวน ทำพร้อมกัน จับเวลา 30 วินาที

## R4 ลำดับเทิร์น
ตัวนับ "เทิร์นของเกม" T เริ่ม 1 และเพิ่ม 1 ทุกครั้งที่เปลี่ยนผู้เล่น
- R4.1 ยามเช้า: (a) อาคมสูงสุด +1 (สูงสุด 10) แล้วเติมอาคมเต็ม (b) ตรวจราหูอมจันทร์ (R8) (c) จั่ว 1 ใบ (d) ทริกเกอร์ turn_start ของผู้เล่นปัจจุบัน (e) พิษทำดาเมจกับยูนิตของผู้เล่นปัจจุบัน (f) ฟื้นฟูทำงาน
- R4.2 ยามกลางวัน+ยามรบ (รวมเป็นช่วงเดียว): ทำ action ใดก็ได้ ลำดับใดก็ได้: ลงการ์ด, วางกับดัก, โจมตี, จบเทิร์น
- R4.3 ยามค่ำ (เมื่อกดจบเทิร์นหรือหมดเวลา 75 วินาที): ทริกเกอร์ turn_end, บัฟ/ดีบัฟแบบ "เทิร์นนี้" หมดอายุ, อาคมที่เหลือแปลงเป็นบารมี (บารมีรวมไม่เกิน 3), นับถอยหลังสถานะ (หลับ/สายสิญจน์/ล็อกเป้า)
- R4.4 จั่วตอนมือเต็ม 5 ใบ = การ์ดที่จั่วลงสุสานทันที (เผา) โดยไม่ทำทริกเกอร์
- R4.5 จั่วจากเด็คว่าง = เสียดวงชะตา 1, 2, 3… สะสมทุกครั้ง

## R5 การลงการ์ด
- R5.1 จ่ายต้นทุนครบ (หลังคำนวณ cost_mod) และมีเป้าหมายที่ถูกต้องอย่างน้อย 1 ถ้าเอฟเฟกต์บังคับเลือกเป้า
- R5.2 ยูนิตลงช่องว่างที่ผู้เล่นเลือก สนามเต็ม = ลงยูนิตไม่ได้ (โทเคนที่ถูกเรียกเกินจะไม่เกิด)
- R5.3 ยูนิตที่เพิ่งลงโจมตีไม่ได้ในเทิร์นนั้น ยกเว้นมีฮึกเหิม
- R5.4 ลำดับเมื่อยูนิตลง: วางบนสนาม → aura เริ่มทำงาน → ทริกเกอร์ play (ปลุกเสก) → ทริกเกอร์ของการ์ดอื่นที่รอ ally_play/enemy_play
- R5.5 คาถา: เลือกเป้า → ตรวจกับดักฝ่ายตรงข้าม (enemy_spell) → ถ้าไม่ถูกยกเลิกให้ทำเอฟเฟกต์ → ลงสุสาน
- R5.6 กับดัก: วางคว่ำในช่องว่าง ศัตรูเห็นแค่ว่ามีกับดัก ทำงานอัตโนมัติครั้งเดียวเมื่อเงื่อนไขเกิด ในเทิร์นของใครก็ได้ ยกเว้นเทิร์นที่วาง

## R6 การโจมตี
- R6.1 ยูนิตแต่ละตัวโจมตีได้ 1 ครั้งต่อเทิร์น (บางการ์ดได้ 2) เป้าหมายคือยูนิตศัตรู หรือดวงชะตาศัตรู
- R6.2 ถ้าศัตรูมียูนิตทวารบาลที่ไม่ได้ถูกสายสิญจน์ ต้องโจมตีทวารบาลก่อน ยกเว้นผู้โจมตีมีเหาะเหิน
- R6.3 ยูนิตที่มีกำบังเลือกเป็นเป้าไม่ได้ (ทั้งการโจมตีและเอฟเฟกต์ของศัตรู) จนกว่ามันจะโจมตีครั้งแรก แล้วกำบังหายถาวร เอฟเฟกต์แบบ all/random ยังโดน
- R6.4 ลำดับ: ประกาศโจมตี → ทริกเกอร์ attack ของผู้โจมตี → กับดัก enemy_attack ของฝ่ายรับ → ถ้าผู้โจมตียังอยู่ คิดดาเมจ
- R6.5 ยูนิตปะทะยูนิต: ทั้งคู่ทำดาเมจเท่า ATK ใส่กันพร้อมกัน ถ้าธาตุฝ่ายหนึ่งชนะทาง ดาเมจของฝ่ายนั้นคูณ 1.5 ปัดลง (R9)
- R6.6 โจมตีดวงชะตา: ทำดาเมจเท่า ATK ไม่มีตัวคูณธาตุ ไม่มีการตอบโต้
- R6.7 หลังดาเมจ: ดูดชีพ (R7) → ตรวจความตาย (R10) → ทริกเกอร์ kill / attacked / damaged

## R7 Keyword (ตรรกะเอนจิน)
- R7.1 ทวารบาล: ดู R6.2
- R7.2 ฮึกเหิม: โจมตีได้ในเทิร์นที่ลง
- R7.3 อมตะ: ครั้งแรกที่จะตาย ให้กลับขึ้นช่องเดิมทันทีด้วย HP 1 (บัฟถาวรยังอยู่ ดีบัฟและสถานะหายหมด) แล้วเสีย keyword อมตะ ถ้าตายด้วยเอฟเฟกต์ "ส่งวิญญาณ" หรือถูกสายสิญจน์อยู่ อมตะไม่ทำงาน
- R7.4 กำบัง: ดู R6.3
- R7.5 สายสิญจน์ X: ลบ keyword, aura และทริกเกอร์ทั้งหมดของเป้า X เทิร์นของเจ้าของเป้า (ไม่ระบุ X = ถาวร) ค่า ATK/HP ไม่เปลี่ยน
- R7.6 ส่งวิญญาณ: การ์ดที่ตายหรือถูกนำออกไปเขตส่งวิญญาณแทนสุสาน ชุบชีวิตไม่ได้ ไม่ทำทริกเกอร์ death
- R7.7 ลิ้มเลือด: ฆ่ายูนิตศัตรูด้วยการโจมตีหรือการถูกโจมตี ได้ +1/+1 ถาวร
- R7.8 ราหูจร: มีเอฟเฟกต์ใน ability_code ภายใต้ trigger "rahu" ซึ่งทำงานตลอดช่วงราหูอมจันทร์
- R7.9 ปลุกเสก = trigger "play"
- R7.10 สิ้นใจ = trigger "death" (ทำงานหลังการ์ดลงสุสาน)
- R7.11 คงกระพัน: ป้องกันดาเมจ 1 ครั้งถัดไปทั้งหมด (ทุกแหล่ง รวมพิษ) แล้วหาย การ์ดที่มี pierce_barrier ข้ามได้
- R7.12 ฟื้นฟู: ยามเช้าของเจ้าของ ฟื้น HP เต็ม
- R7.13 เหาะเหิน: ไม่ต้องโจมตีทวารบาลก่อน
- R7.14 บวงสรวง: ต้นทุนเพิ่มเติม ส่งยูนิตฝ่ายเราลงสุสาน ผู้ปกครองและเทพบวงสรวงไม่ได้
- R7.15 เมตตามหานิยม: ในฐานะ keyword บนยูนิต ไม่มีผลเอง ใช้เป็นเงื่อนไขของการ์ดอื่น เอฟเฟกต์ steal ใช้กับผู้ปกครอง/เทพไม่ได้
- R7.16 พิษ X: บนยูนิตผู้โจมตี = ใส่สถานะพิษ X ให้เป้าที่โดนตี; บนยูนิตป้องกัน = ใส่ให้ผู้ที่ตีมัน สถานะพิษ: ยามเช้าของเจ้าของ เสีย HP X ทั้งหมด 2 ครั้งแล้วหาย ซ้อนกันไม่ได้ (ใช้ค่ามากสุดและรีเซ็ตนับ)
- R7.17 อวตาร: แบบ avatar ใน ability_code
- R7.18 หลับ: โจมตีไม่ได้ ทริกเกอร์ attack ไม่ทำงาน นับลดตอนยามค่ำของเจ้าของ

## R8 ราหูอมจันทร์
- R8.1 ช่วงราหู = เทิร์นของเกม T ที่ T mod 3 == 0 และเทิร์นถัดไปของอีกฝ่าย (T=3–4, 6–7, 9–10 …) ตรวจตอน R4.1(b)
- R8.2 ระหว่างช่วงราหู: ยูนิตเผ่าผีทุกตัว +1 ATK, ยูนิตเผ่าเทพ -1 ATK (ยกเว้นพระราหู, ต่ำสุด 0), ผู้ปกครองไม่ได้รับผล, trigger "rahu" ของทุกการ์ดทำงาน (แบบ aura ระหว่างช่วง หรือครั้งเดียวตอนเริ่มช่วง ถ้าระบุ once:true)
- R8.3 เอฟเฟกต์ start_rahu{rounds:n} เปิดช่วงราหูทันทีนาน n รอบ (1 รอบ = 2 เทิร์น) ถ้าทับช่วงเดิม ให้ใช้วันสิ้นสุดที่ไกลกว่า

## R9 ธาตุ
- R9.1 วงชนะทาง: น้ำ > ไฟ > ดิน > ลม > น้ำ อากาศไม่ชนะและไม่แพ้ใคร
- R9.2 ตัวคูณ 1.5 ใช้เฉพาะดาเมจจากการปะทะยูนิต ไม่ใช้กับคาถาและเอฟเฟกต์

## R10 ความตายและลำดับทริกเกอร์
- R10.1 หลังทุก action ตรวจยูนิตที่ HP ≤ 0 พร้อมกันทั้งหมด จัดการอมตะ (R7.3) ก่อน แล้วย้ายที่เหลือลงสุสาน (หรือเขตส่งวิญญาณ) ตามลำดับช่องซ้ายไปขวา ผู้เล่นปัจจุบันก่อน
- R10.2 คิวทริกเกอร์: ทริกเกอร์ที่เกิดพร้อมกันเข้าคิว ผู้เล่นปัจจุบันก่อน เรียงตามช่องซ้ายไปขวา แล้วการ์ดในช่องกับดัก ทำทีละตัวจนคิวว่าง ทริกเกอร์ใหม่ต่อท้ายคิว
- R10.3 กันลูปไม่รู้จบ: ทริกเกอร์เกิน 100 ครั้งใน action เดียว ให้หยุดคิวและบันทึก log เตือน
- R10.4 ของขลังติดยูนิตลงสุสานพร้อมยูนิตที่ติด

## R11 กฎความยิ่งใหญ่
- R11.1 การ์ดที่ระดับต่ำกว่าผู้สรรสร้าง ไม่สามารถ destroy, steal, purge (ตอนอยู่บนสนาม), lock_on หรือ transform ยูนิตเผ่าเทพระดับผู้สรรสร้างได้ ดาเมจปกติยังทำได้
- R11.2 ยูนิตหมวดผู้ปกครองและเทพเจ้า: ถูก steal ไม่ได้, บวงสรวงไม่ได้, ถูกสิงร่างไม่ได้, ถูกฟื้นจากสุสานศัตรูมาเป็นของเราไม่ได้
- R11.3 ข้อความในเกมที่พูดถึงการ์ดผู้ปกครองใช้ถ้อยคำสุภาพ ไม่มีอีโมตล้อเลียนกับการ์ดกลุ่มนี้

## R12 ชนะ / เสมอ
- R12.1 ดวงชะตาฝ่ายใดเหลือ ≤ 0 ฝ่ายนั้นแพ้ ถ้าทั้งคู่เหลือ ≤ 0 พร้อมกัน = เสมอ
- R12.2 ยอมแพ้ได้ทุกเมื่อ, หลุดเกิน 60 วินาที = แพ้
- R12.3 ครบ 40 เทิร์นของเกม = ฝ่ายที่ดวงชะตามากกว่าชนะ เท่ากัน = เสมอ

## R13 เด็คสำเร็จรูป (สำหรับผู้เล่นใหม่ + AI)
ให้ AI ผู้เขียนโค้ดประกอบจาก siam_duel_cards.json ตามธีม โดยผ่าน R2:
- "ทัพกรุงศรี" (มนุษย์/ดิน-ไฟ): ผู้ปกครองระดับ Legendary, 8 อาชีพ, ชาวบางระจัน, ของขลัง
- "รัตติกาลผี" (ผี/ราหู): ผี Common–Epic, ปลุกพราย, พิธีบูชาราหู
- "หิมพานต์" (หิมพานต์/ลม-น้ำ): สัตว์หิมพานต์, วรรณคดี
- "ลงกา" (อสูร/ไฟ): ยักษ์, ไมยราพ, กุมภกรรณ
แต่ละเด็คใส่ระดับตำนานได้ 1 ใบ ไม่มีพระเจ้าและผู้สรรสร้าง

## R15 การ์ดจำนวนจำกัด
- R15.1 การ์ดระดับพระเจ้าและผู้สรรสร้างมี max_supply ต่อแบบ แต่ละใบที่ผลิตมีเลขรันนัมเบอร์ไม่ซ้ำ (card_instances)
- R15.2 ผลิตครบแล้วการ์ดแบบนั้นออกจากพูลสุ่มทันที
- R15.4 จำนวนทั้งเซิร์ฟเวอร์: การ์ดระดับพระเจ้า 3 ใบต่อแบบ (4 แบบ รวม 12 ใบ) การ์ดระดับผู้สรรสร้าง 1 ใบต่อแบบ (10 แบบ รวม 10 ใบ) ห้ามผลิตเพิ่มไม่ว่ากรณีใด รวมถึงกิจกรรมและของขวัญจากแอดมิน
- R15.5 เลขรันแสดงเป็นเลขไทยรูปแบบ "ลำดับ/จำนวนทั้งหมด" เช่น ๑/๓ ๒/๓ ๓/๓ และ ๑/๑ ลำดับเริ่มที่ ๑ ตามลำดับที่ผลิต
- R15.6 ตู้ปกติไม่มีการ์ดผู้สรรสร้าง ถ้าสุ่มได้ระดับพระเจ้าแต่ครบทุกแบบแล้ว ให้สุ่มใหม่เป็นระดับตำนาน
- R15.7 การ์ดผู้สรรสร้างได้จากตู้ผู้สรรสร้าง (Event) เท่านั้น: บัญชีต้องสุ่มตู้ปกติสะสมครบ 10,000 ครั้ง แอดมินเปิดเป็นรอบ รอบละ 1 แบบ ค่าสุ่มเป็นโกลด์และถูกเผาทั้งหมด รายละเอียดใน economy.md
- R15.3 ในการดวล การ์ดที่มีเลขรันทำงานเหมือนการ์ดปกติ เลขมีผลแค่การแสดงผลและการสะสม

## R16 ฉบับสะสม (Collector Edition)
- R16.1 การ์ดระดับตำนาน พระเจ้า และผู้สรรสร้าง (20 แบบ) ทุกใบมีฉบับสะสมผูกกับใบรับรองของใบนั้น: ภาพด้านหน้าและด้านหลังความละเอียดสูง 2160×3240 (ไม่มีโมเดล 3D) ด้านหลังเป็นลายประจำแบบ
- R16.2 ฉบับสะสมใช้ดูสะสมและเทรดเท่านั้น ไม่มีผลในการดวล ในการดวลการ์ดใช้ภาพมาตรฐานและค่าพลังปกติ
- R16.3 ไฟล์ฉบับสะสมเข้ารหัส ปลดล็อกได้ด้วยกุญแจของการ์ดใบนั้นเท่านั้น เก็บถอดรหัสในตู้นิรภัยบนเครื่องเจ้าของ เซิร์ฟเวอร์เก็บเฉพาะไฟล์ที่เข้ารหัสไว้ส่งต่อเมื่อเปลี่ยนมือ
- R16.4 เมื่อเปลี่ยนมือ (ตลาดกลางหรือเทรด P2P 1:1) ฉบับสะสมย้ายไปพร้อมการ์ด และลบออกจากตู้นิรภัยของเจ้าของเดิม
- R16.5 เอฟเฟกต์วาดสดตามมุมเอียง: ตำนาน = ประกายไฟแดง, พระเจ้า = เกล็ดทองระยิบระยับ, ผู้สรรสร้าง = ฟอยล์รุ้งโฮโลแกรม; ลายประกายสุ่มจาก cert_id ทำให้แต่ละใบไม่ซ้ำกัน และสลักเลขรันเลขไทย
- R16.6 ตราของแท้แสดงเฉพาะเมื่อตรวจใบรับรองผ่าน สำเนาภาพที่ถูกคัดลอกไปไม่มีตรานี้

## R17 ประกาศและการเปิดเผยชื่อ
- R17.1 ตลาดกลาง: ประกาศการ์ดพระเจ้า/ผู้สรรสร้างตอนวางขายและขายได้ โดยไม่ระบุชื่อ
- R17.2 เทรด P2P 1:1: ประกาศชื่อผู้รับการครอบครอง ผู้รับต้องยืนยันก่อน ข้อความเซ็นจากเครื่องผู้รับ เซิร์ฟเวอร์ไม่บันทึกความเชื่อมโยง
- R17.3 เจ้าของตั้งค่ารายการ์ดว่าจะแสดงชื่อเมื่อใช้การ์ดในดวล/หน้าจอผู้ชมหรือไม่ (ค่าเริ่มต้นซ่อน) ชื่อที่แสดงต้องมีลายเซ็นกุญแจการ์ดกำกับ

## R14 Determinism และความปลอดภัย
- R14.1 เอนจินเป็นฟังก์ชันบริสุทธิ์ applyAction(state, action, rng) → {state, events} ใช้ seeded RNG เท่านั้น
- R14.2 ทุก action ตรวจความถูกต้องบนเซิร์ฟเวอร์ client ส่งได้แค่ intent
- R14.3 state ที่ส่งให้ผู้เล่นแต่ละคนซ่อนมือและเด็คของอีกฝ่าย และซ่อนหน้ากับดักที่ยังคว่ำ
- R14.4 ทุกเกมบันทึก seed + รายการ action เพื่อ replay ได้ครบ

# ภาษาความสามารถ ability_code

ทุกการ์ดมี `ability_code` เป็น array ของกฎย่อย แต่ละกฎมีรูปแบบอย่างใดอย่างหนึ่ง:

```json
{ "on": "<trigger>", "if": { ...เงื่อนไข }, "once": true, "do": [ { "<effect>": { ...พารามิเตอร์ } } ] }
{ "aura": { "target": "<target>", "filter": { ... }, "atk": 1, "hp": 2, "grant": ["ทวารบาล"], "rule": "<rule-key>" } }
{ "special": "<handler>", ...พารามิเตอร์ }
```

## Trigger (`on`)
| ค่า | เกิดเมื่อ |
| --- | --- |
| play | การ์ดนี้ลงสนาม/ถูกใช้ (ปลุกเสก) |
| death | การ์ดนี้ตายลงสุสาน (สิ้นใจ) |
| turn_start / turn_end | ยามเช้า/ยามค่ำของเจ้าของ |
| attack | การ์ดนี้ประกาศโจมตี |
| attacked | การ์ดนี้ถูกโจมตี (หลังดาเมจ) |
| after_hit | การ์ดนี้ทำดาเมจจากการโจมตีแล้ว |
| kill | การ์ดนี้ฆ่ายูนิตศัตรูได้ |
| ally_death / enemy_death / any_death | ยูนิตฝ่ายเรา/ศัตรู/ใดก็ได้ตาย |
| ally_revived | ฝ่ายเราชุบชีวิตยูนิตสำเร็จ |
| enemy_play | ศัตรูลงยูนิต |
| enemy_spell | ศัตรูใช้คาถา (ก่อนทำผล) |
| enemy_revive | ศัตรูกำลังชุบชีวิต (ก่อนทำผล) |
| enemy_attack | ยูนิตศัตรูประกาศโจมตี |
| first_targeted | ครั้งแรกที่การ์ดนี้ถูกเลือกเป็นเป้าของศัตรู |
| rahu | ช่วงราหูอมจันทร์ (R8) |

## Target
self, self_player, enemy_player, chosen_enemy_unit, chosen_ally_unit, chosen_unit, chosen_enemy_units (มี count), all_enemy_units, all_ally_units, all_units, other_ally_units, random_enemy_unit, enemy_strongest (ATK สูงสุด เสมอเลือกต้นทุนสูง), enemy_lowest_cost, adjacent_allies, attacker, attack_target, killer, chosen_enemy_slot_card (กับดัก/ของขลังศัตรู), bearer (ยูนิตที่ของขลังติดอยู่), event_unit (ยูนิตในเหตุการณ์ที่ทำให้ทริกเกอร์)

## Filter (ใช้กับ target/if)
tribe, element, category, name, name_contains, cost_lte, cost_gte, cost_eq, rarity, rarity_gte, hp_lte, status ("asleep"/"sealed"), not_category, exclude_self
