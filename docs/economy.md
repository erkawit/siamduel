# สยามมินทร์ดูเอล — เศรษฐกิจโกลด์ และตู้ผู้สรรสร้าง (v1)

สมมติฐาน: ผู้เล่นประจำ ~200 คน (เซิร์ฟเวอร์ต่ำกว่า 500 คน), ทุกตู้จ่ายด้วยโกลด์อย่างเดียว ค่าทั้งหมดแก้ได้จากหลังบ้าน (ตาราง game_config)

## 1. แหล่งได้โกลด์ (สร้างโกลด์ใหม่เข้าระบบ)
| แหล่ง | รางวัล | เพดาน |
| --- | --- | --- |
| ภารกิจรายวัน 6 ข้อ | 200 / ข้อ | 1,200 / วัน |
| ภารกิจรายสัปดาห์ | 3,500 / สัปดาห์ | (~500 / วัน) |
| ดวลผู้เล่น (PvP) | ชนะ 60 · แพ้ 20 | นับรางวัล 20 เกม / วัน (~800) |
| อารีน่า / ประชันกิลด์ | ตามอันดับ 500–5,000 / ซีซัน | ต่อซีซัน |
| กิจกรรมในเกม | ตั้งจากหลังบ้าน | เฉลี่ย ~300 / วัน |
ผู้เล่นขยัน ≈ 2,800 โกลด์/วัน · ผู้เล่นทั่วไป ≈ 1,000 โกลด์/วัน
กันฟาร์ม: รางวัล PvP นับเฉพาะคู่ต่างบัญชีที่ไม่ได้เจอกันเกิน 3 ครั้ง/วัน

## 2. ที่เผาโกลด์ออกจากระบบ
- ตู้กาชาปกติ 100 โกลด์/ครั้ง (10 ครั้ง 1,000) — เผาทั้งหมด
- ตู้ผู้สรรสร้าง 5,000 โกลด์/ครั้ง — เผาทั้งหมด
- ค่าธรรมเนียมตลาดกลาง 5% — เผา
- โกลด์ที่เทรดระหว่างผู้เล่นหรือซื้อการ์ดในตลาด แค่ย้ายเจ้าของ ไม่สร้างไม่เผา (ยกเว้นค่าธรรมเนียม)

## 3. ตู้กาชาปกติ (อัตราใหม่)
| ระดับ | อัตรา |
| --- | --- |
| ธรรมดา | 60.01% |
| ทั่วไป | 27% |
| หายาก | 9% |
| มหากาพย์ | 2.89% |
| ตำนาน | 1% (soft pity 150, hard pity 200) |
| พระเจ้า | **0.001%** (ตกลงแล้ว) |
| ผู้สรรสร้าง | **0% — ไม่อยู่ในตู้ปกติ** |
ผู้เล่นขยันสุ่มได้ ~28 ครั้ง/วัน → ครบ 10,000 ครั้งในเวลาประมาณ 1 ปี

หมายเหตุพระเจ้า: มีทั้งเซิร์ฟเวอร์ 12 ใบ ทั้งเซิร์ฟเวอร์สุ่มรวม ~5,600 ครั้ง/วัน
- อัตรา 0.1% → หมดใน ~2 วัน · 0.01% → ~3 สัปดาห์ · **0.001% → ~7 เดือน (แนะนำ)**
- การแลกการ์ดพระเจ้า: 50,000 แต้มบุญ (ตกลงแล้ว) แลกได้เฉพาะแบบที่ยังออกไม่ครบ

## 3.1 แต้มบุญ
ผูกกับบัญชี เทรดไม่ได้ ซื้อด้วยโกลด์ไม่ได้ (กันคนรวยกวาดการ์ดพระเจ้า)
| แหล่ง | ได้ |
| --- | --- |
| สุ่มตู้ปกติ | 1 / ครั้ง |
| ถวายการ์ดซ้ำ (เกิน 3 ใบต่อชื่อ) | ธรรมดา 1 · ทั่วไป 2 · หายาก 5 · มหากาพย์ 20 · ตำนาน 100 |
| ทำบุญรายวัน (เข้าเกมต่อเนื่อง) | วันละ 5 · ครบ 7 วันต่อเนื่อง +30 |
| กิจกรรมเทศกาล (สงกรานต์ ลอยกระทง ออกพรรษา ฯลฯ) | ตั้งจากหลังบ้าน 200–1,000 |
| จัดอันดับอารีน่าปลายซีซัน | 100–1,000 |
ผู้เล่นขยัน ≈ 40–50 แต้ม/วัน → 50,000 แต้ม ≈ 3 ปี (เป้าระยะยาว ใครถึงก่อนได้ก่อน เพราะมีแค่ 3 ใบต่อแบบ)
ร้านแต้มบุญ (ใช้ระหว่างทาง): การ์ดมหากาพย์ที่เลือกได้ 1,500 · การ์ดตำนานที่เลือกได้ 6,000 · กรอบโปรไฟล์/หลังการ์ดพิเศษ 500–2,000 · การ์ดพระเจ้า 50,000

## 4. ตู้ผู้สรรสร้าง (Event เท่านั้น)
- สิทธิ์เข้า: บัญชีที่สุ่มตู้ปกติสะสมครบ 10,000 ครั้ง (นับตลอดชีพ ไม่รีเซ็ต)
- จัดเป็นรอบโดยแอดมิน: ทุกรอบเลือกการ์ดผู้สรรสร้าง 1 แบบที่ยังไม่มีเจ้าของ กำหนดวันเริ่ม/จบ (ค่าเริ่มต้น 30 วัน)
- ค่าสุ่ม 5,000 โกลด์/ครั้ง โอกาส 0.5% (1 ใน 200) ไม่มี pity ไม่มีรางวัลปลอบใจ
- มีผู้ได้ → รอบจบทันที ประกาศทั้งเซิร์ฟเวอร์ "การ์ด {ชื่อ} ระดับผู้สรรสร้าง มีผู้ได้รับไปดูแลต่อแล้ว" ไม่บอกชื่อ
- หมดเวลาไม่มีผู้ได้ → การ์ดกลับคลัง แอดมินเปิดรอบใหม่ได้ โกลด์ที่ใช้ไปถูกเผาแล้ว ไม่คืน
- ประมาณการ (ผู้มีสิทธิ์ 30 คน ใช้โกลด์ครึ่งหนึ่งของรายได้): ~8 ครั้ง/วัน → โอกาสมีผู้ได้ใน 7 วัน 26% · 14 วัน 45% · 30 วัน 72% · 60 วัน 92% · เผาเฉลี่ย ~1,000,000 โกลด์/รอบ
- ช่วงแรกยังไม่มีใครครบ 10,000 ครั้ง (รอบแรกจริงประมาณ 1 ปีหลังเปิด) เซิร์ฟเวอร์ทดสอบให้แอดมินลดเกณฑ์ได้ชั่วคราว

## 5. ความเป็นส่วนตัวในตู้ผู้สรรสร้าง
- เซิร์ฟเวอร์ตรวจสิทธิ์จากตัวนับครั้งของบัญชี (เหมือน pity) แต่การ์ดที่ได้ถูกออกใบรับรองให้กุญแจใหม่บนเครื่องผู้ได้ และลบความเชื่อมโยงกับบัญชีทันที (ระดับ 2: ใช้บัตรสุ่มลายเซ็นปิดตา)
- เก็บไว้เพียง: รหัสอ้างอิง cert_id, แบบการ์ด, เลข ๑/๑, วันที่ออก

## 5.1 ประกาศและการเปิดเผยชื่อ
- ขายผ่านตลาดกลาง (พระเจ้า/ผู้สรรสร้าง): ประกาศตอนวางขายและตอนขายได้ ไม่บอกชื่อใคร
- เทรด P2P 1:1 (พระเจ้า/ผู้สรรสร้าง): ประกาศชื่อผู้รับการครอบครอง "การ์ด {ชื่อการ์ด} ระดับ {ระดับ} {เลขรัน} ได้รับการครอบครองโดย {ชื่อผู้รับ}" ผู้รับเห็นคำเตือนและกดยืนยันก่อนรับ; ข้อความประกาศสร้างและเซ็นจากเครื่องผู้รับ เซิร์ฟเวอร์ส่งต่อแบบชั่วคราว ไม่บันทึกความเชื่อมโยงชื่อกับการ์ดลงฐานข้อมูล
- หลังจากนั้นเจ้าของตั้งค่ารายการ์ด "แสดงชื่อผู้ครอบครองเมื่อใช้การ์ด" (ค่าเริ่มต้น: ซ่อน) ถ้าเปิด คู่ดวลและผู้ชมเห็น "ครอบครองโดย {ชื่อ}" พร้อมลายเซ็นจากกุญแจการ์ด จึงปลอมชื่อไม่ได้ ปิดเมื่อไรก็กลับเป็นไม่ระบุชื่อ
- ชื่อที่ประกาศไปแล้วตอนเทรดลบคืนไม่ได้ (คนในเซิร์ฟเวอร์เห็นไปแล้ว)

## 6. ตัวชี้วัดที่หลังบ้านต้องแสดง
โกลด์ที่สร้างต่อวัน · โกลด์ที่เผาต่อวัน (แยกตามตู้/ค่าธรรมเนียม) · โกลด์หมุนเวียนรวม · ผู้มีสิทธิ์ตู้ผู้สรรสร้าง (จำนวน ไม่ระบุตัว) · การ์ดพระเจ้า/ผู้สรรสร้างคงเหลือ
ถ้าโกลด์หมุนเวียนโตเกิน 10%/เดือน → ลดรางวัลหรือเพิ่มกิจกรรมเผา

## 7. ฉบับสะสม (แทน 3D)
- การ์ดระดับตำนานขึ้นไป 20 แบบ: ด้านหน้าความละเอียดสูง 2160×3240 + ด้านหลังเฉพาะแบบ 2160×3240
- ด้านหน้า: ภาพ upscale + กรอบ + เอฟเฟกต์สด (ตำนาน ประกายไฟ · พระเจ้า เกล็ดทอง · ผู้สรรสร้าง ฟอยล์รุ้ง)
- ด้านหลัง: ลายประจำแบบการ์ด เกมสลักชื่อ เลขรันเลขไทย และตราของแท้ทับตอนแสดงผล
- ใช้เก็บและเทรดเท่านั้น เข้ารหัสด้วยกุญแจการ์ด ย้ายไปพร้อมการ์ดเมื่อเปลี่ยนมือ (กฎ R16)
