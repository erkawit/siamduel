# สยามมินทร์ดูเอล — ระบบสอนเล่น กติกาในเกม และกติกาพิเศษ (v1)

## 1. ระบบสอนเล่นแบบจับมือ (บังคับเล่นครั้งแรก ข้ามได้เมื่อจบบทที่ 1)
หลักการ: ดวลจริงกับ "หมอผีเฒ่า" ใช้เอนจินเดียวกับเกมจริง แต่จัดไพ่และ seed ตายตัว ทุกขั้นตอน
- ทำให้หน้าจอมืดลง เปิดไฟเฉพาะสิ่งที่ต้องกด มีลูกศรและมือชี้
- กดได้เฉพาะ action ที่บทเรียนต้องการ (action อื่นถูกล็อก)
- ถ้าผู้เล่นทำผิด (เช่น ลากไปผิดช่อง) เด้งข้อความ "ยังไม่ถูก เพราะ…" แล้วให้ลองใหม่ ไม่เสียอะไร
- ทำถูกขึ้น "ถูกต้อง!" พร้อมเหตุผลสั้น ๆ แล้วไปขั้นถัดไป
- จบแต่ละบทได้รางวัล (โกลด์ + การ์ด) จูงใจให้เรียนครบ

## 2. กติกาในเกม
- เมนู "ตำรากติกา": สรุปกติกา R1–R17 เป็นภาษาง่าย มีภาพประกอบ แยกหัวข้อ (เทิร์น · อาคม · การโจมตี · คีย์เวิร์ด · ธาตุ · ราหู · ตาย/ชุบชีวิต · จัดเด็ค)
- พจนานุกรมคีย์เวิร์ด: ทวารบาล เหาะเหิน ฮึกเหิม กำบัง คงกระพัน อมตะ พิษ ปลุกพราย ส่งวิญญาณ ฯลฯ พร้อมตัวอย่าง
- ทุกการกระทำที่ไม่ถูกกติกาในดวลจริง ขึ้นเหตุผลเป็นภาษาไทยเสมอ (เอนจินคืนรหัสเหตุผล เช่น NOT_ENOUGH_ARKOM, MUST_ATTACK_GUARD)

## 3. กติกาพิเศษ (Ruleset) — ตั้งจากหลังบ้าน
เอนจินรับ `ruleset` เป็นค่าตั้งต้นของแมตช์ ค่าเริ่มต้นคือกติกามาตรฐาน หลังบ้านสร้างชุดกติกาพิเศษแล้วผูกกับกิจกรรม / ห้องอารีน่า / ห้องส่วนตัวได้

| ตัวอย่างกติกาพิเศษ | ค่าที่เปลี่ยน |
| --- | --- |
| คืนราหูนิรันดร์ | ราหูอมจันทร์ทุกเทิร์น |
| ศึกสามัญชน | ใช้ได้เฉพาะการ์ดธรรมดา–หายาก |
| ศึกธาตุเดียว | ทุกการ์ดในเด็คต้องธาตุเดียวกัน |
| อาคมล้นฟ้า | เริ่มเกมอาคม 4 สูงสุด 12 |
| ดวลสายฟ้า | เด็ค 20 ใบ ดวงชะตา 20 จำกัดเวลาเทิร์นละ 30 วินาที |
| สงกรานต์ | ธาตุน้ำ ×2 แทน ×1.5 |
| ศึกเทพห้าม | ห้ามเทพและผู้ปกครอง |

ค่าที่ปรับได้: ดวงชะตาเริ่ม · ขนาดเด็ค · ขนาดมือ · อาคมเริ่ม/สูงสุด · รอบราหู · ตัวคูณธาตุ · ระดับการ์ดที่อนุญาต · เผ่า/ธาตุที่อนุญาต · การ์ดต้องห้าม · เวลาต่อเทิร์น · จำนวนช่องยูนิต/กับดัก
ความปลอดภัย: ruleset ถูกเซ็นโดยเซิร์ฟเวอร์ ทั้งสองฝ่ายเห็นกติกาก่อนกดยอมรับแมตช์ ใน P2P ทั้งคู่ต้องเซ็นยอมรับ ruleset เดียวกัน
