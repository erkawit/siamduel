# สยามมินทร์ดูเอล — หน้าดวล ตู้สุ่ม ห้องพัก ดวลทีม 2v2 การเก็บข้อมูล P2P/ออนไลน์ กิลด์ และ AI (v1)

## 1. หน้าดวล "กระดานชนวน"

### 1.1 ผัง (PC 16:9 · มือถือ 9:16 ใช้ผังเดียวกันแบบแนวตั้ง)
```
┌─────────────────────────────────────────────────────────────┐
│ [รูปคู่ดวล] ชื่อ  ดวงชะตา ◉30   อาคม ◆◆◆◇◇  บารมี ●●○      │  ← แถบคู่ดวล
│              ไพ่ในมือคู่ดวล: 🂠🂠🂠🂠 (เห็นแค่หลังการ์ด + จำนวน)  │
│ [เด็ค 22]  [กับดัก ▣][กับดัก ▣]                    [สุสาน 3]│  ← กับดักคว่ำ
│        [ยูนิต][ยูนิต][ยูนิต][ยูนิต][ยูนิต]                    │  ← สนามคู่ดวล
│ ═════════ เส้นชอล์กกลางกระดาน · 🌘 ราหู · เทิร์น 5 ══ [จบเทิร์น] │
│        [ยูนิต][ยูนิต][ยูนิต][ยูนิต][ยูนิต]                    │  ← สนามเรา
│ [สุสาน 1]  [กับดัก][กับดัก]                        [เด็ค 24] │
│ [รูปเรา] ชื่อ  ดวงชะตา ◉30   อาคม ◆◆◆◆◇  บารมี ●○○          │
│        ไพ่ในมือเรา (หน้าการ์ด สูงสุด 5 ใบ แบบพัด)             │
└─────────────────────────────────────────────────────────────┘
```
- พื้นกระดาน: แผ่นกระดานชนวนสีดำเทา ขอบไม้สักแกะลายกนกปิดทอง เส้นแบ่งช่องเป็นเส้นชอล์กสีขาวนวล + ทองจาง
- ช่องยูนิต/กับดักวาดด้วยชอล์ก ไฮไลต์ทองเมื่อวางได้ แดงเมื่อวางไม่ได้
- ราหู: ไอคอนดวงจันทร์ตรงกลาง เปลี่ยนเป็นจันทร์ถูกอมพร้อมแสงม่วงเมื่อถึงช่วงราหู
- มือถือ: ไพ่ในมือเราอยู่ล่างสุด แตะเพื่อยก แตะช่องเพื่อวาง กดค้างดูการ์ดขยาย

## 2. หน้าตู้สุ่มกาชา
- ฉากหลัง: วิหารไทยกลางคืน ตู้สุ่มเป็น "บุษบกทอง" ตรงกลาง มีดอกบัวทองยักษ์ด้านใน
- ปุ่ม: สุ่ม 1 ครั้ง / สุ่ม 10 ครั้ง (ราคาโกลด์) · ปุ่ม "กติกา ?" · แถบความคืบหน้าการันตีตำนาน · แถบสิทธิ์ 10,000 ครั้ง
- แอนิเมชันสุ่ม: ดอกบัวหุบ → เรืองแสงตามระดับสูงสุดที่ได้ → บานออก → การ์ดลอยออกมาคว่ำ → พลิกเปิดทีละใบ
  - สีแสง: ขาว (ธรรมดา) · เขียว · ฟ้า · ม่วง · แดงเพลิง (ตำนาน) · ทองระยิบระยับ (พระเจ้า)
- ตู้ผู้สรรสร้าง (แสดงเฉพาะเมื่อหลังบ้านเปิดรอบ): บุษบกเพชรสีรุ้งลอยกลางฟ้า การ์ดของรอบลอยหมุนอยู่ด้านบนแบบเงามืด ป้ายชื่อเทศกาล + เวลานับถอยหลัง

## 3. ห้องพักส่วนตัว (เรือนไทยของผู้เล่น)
- ฉาก: เรือนไทยไม้สักยามค่ำ มีโต๊ะเตรียมดวล ตู้เก็บการ์ด ตัวละครของผู้เล่นยืนในห้อง
- จุดที่กดได้: ตู้การ์ด (คลัง) · โต๊ะจัดเด็ค · ตู้นิรภัย (ฉบับสะสม) · กระจก (เปลี่ยนชุด/ท่าตัวละคร) · ประตู (ออกสู่โลก/ล็อบบี้)
- **เซ็ตการ์ด 3 เซ็ต** ต่อผู้เล่น แต่ละเซ็ตตั้งชื่อ เลือกปกหลังการ์ด และผูกโหมดได้:
  | โหมด | กติกาที่ตรวจ |
  | --- | --- |
  | ดวล AI / ฝึกส่วนตัว | กติกามาตรฐาน |
  | อารีน่าจัดอันดับ | มาตรฐาน + ห้ามการ์ดที่ถูกแบนในซีซัน |
  | ดวลเพื่อน P2P / ห้องส่วนตัว | ตาม ruleset ที่ห้องตั้ง |
  | ศึกกิลด์ | ตาม ruleset ของกิลด์/ฤดูศึก |
  | ทีม 2v2 | กติกาทีม (ข้อ 4) |
  | กิจกรรม/กติกาพิเศษ | ตาม ruleset กิจกรรม |
- เซ็ตเดียวผูกได้หลายโหมด เกมตรวจความถูกต้องทันทีที่บันทึก ขึ้นเหตุผลถ้าใช้โหมดนั้นไม่ได้
- รายการเด็คเก็บในเครื่องผู้เล่น (อ้างอิงใบรับรองการ์ด) เซิร์ฟเวอร์ไม่รู้ว่าใครจัดเด็คอะไร

## 4. ดวลทีม 2v2 — ทำได้ ใช้แบบ "เทิร์นร่วมทีม" (มาตรฐานสากลแบบ Two-Headed Giant)
| หัวข้อ | กติกา |
| --- | --- |
| ดวงชะตา | ทีมใช้ร่วมกัน 40 |
| เด็ค / มือ / อาคม / บารมี | แยกของแต่ละคน (เด็ค 30, มือ 5) |
| เทิร์น | ทีมเล่นพร้อมกันในเทิร์นเดียว ทั้งสองคนลง/โจมตีได้ เวลาทีมละ 120 วินาที |
| ลำดับเริ่ม | ทีมที่เริ่มก่อน ทั้งสองคนไม่จั่วเทิร์นแรก |
| สนาม | ฝั่งละ 6 ช่องยูนิต (คนละ 3) + กับดักคนละ 1 ช่อง |
| มองเห็น | เพื่อนร่วมทีมเห็นไพ่ในมือกันได้ ศัตรูเห็นแค่หลังการ์ด |
| เป้าหมาย | "ศัตรูทุกตัว" = ยูนิตของทั้งสองศัตรู · "ดวงชะตาศัตรู" = ดวงชะตาทีม · "ฝ่ายเรา" = รวมยูนิตเพื่อน |
| ทวารบาล | ปกป้องทั้งทีม |
| ราหู | นับตามเทิร์นของเกม (ทีม A, ทีม B = 2 เทิร์น) |
| จัดเด็ค | ต่อทีม: ตำนานขึ้นไปรวมไม่เกิน 4 · ผู้สรรสร้างรวมไม่เกิน 1 · การ์ดชื่อเดียวกันรวมไม่เกิน 3 |
| การกระทำพร้อมกัน | เข้าคิวทีละ action (ใครกดก่อนได้ก่อน) มีปุ่มส่งสัญญาณ (ping) และแชททีม |
| แพ้ | ดวงชะตาทีมเหลือ 0 หรือเด็คของคนใดคนหนึ่งหมดแล้วจั่วไม่ได้ครบ 3 ครั้ง |
ต้องเพิ่มในเอนจิน: owner ต่อยูนิต, ทีม, ตัวนับเทิร์นทีม และทดสอบ T31–T36 (เป้าหมายข้ามทีม, ทวารบาลทีม, ราหูทีม, ดวงชะตาร่วม, คิว action, เด็คหมด)

## 5. การเก็บการ์ดและตัวเกม
### 5.1 การ์ด (แบบผสม)
| ระดับ | เก็บที่ | เหตุผล |
| --- | --- | --- |
| ธรรมดา–มหากาพย์ | คลังบัญชีบนเซิร์ฟเวอร์ (เปลี่ยนเครื่องได้สะดวก) | ของเยอะ ไม่ต้องเป็นความลับ |
| ตำนาน · พระเจ้า · ผู้สรรสร้าง | ตู้นิรภัยในเครื่องผู้เล่นเท่านั้น | เซิร์ฟเวอร์เก็บแค่ทะเบียน (cert_id, แบบ, เลขรัน, วันที่, กุญแจสาธารณะ) ไม่มีเจ้าของ |
- ถ้าต้องการให้ทุกระดับอยู่ในเครื่องทั้งหมด ใช้สถาปัตยกรรมเดิมได้ทันที (ทุกใบมีใบรับรอง)
- เวลาดวล เกมอ้างอิงการ์ดในเครื่องด้วยใบรับรอง + ลายเซ็นกุญแจการ์ด ไม่ส่งตัวการ์ดขึ้นเซิร์ฟเวอร์

### 5.2 ตัวเกมในเครื่อง (PWA)
- เกมเป็น Progressive Web App: กด "ติดตั้ง" จากเบราว์เซอร์ ได้ไอคอนบนหน้าจอ PC/มือถือ ไฟล์เกม ภาพการ์ด และเอนจินถูกเก็บในเครื่อง เล่นได้แม้ออฟไลน์ (ดวล AI, จัดเด็ค, ดูคลัง, ดวล P2P ใน Wi-Fi เดียวกัน)
- ตู้นิรภัย: IndexedDB + เข้ารหัส AES-256-GCM กุญแจจาก Argon2id (ตามเอกสารสถาปัตยกรรม) + สำรองไฟล์ .siamvault

### 5.3 ห้องดวล P2P (เครื่องผู้เล่นเป็นห้อง)
1. ผู้สร้างกด "สร้างห้อง" → ได้รหัสห้อง 8 ตัว + ลิงก์ + QR Code เช่น `https://siamduel.app/j/K7Q2-9MXA#<กุญแจห้อง>`
2. ส่งลิงก์ทาง LINE/แชท หรือให้อีกฝ่ายสแกน QR
3. เครื่องสองฝั่งเชื่อมกันตรงด้วย WebRTC (ใช้เซิร์ฟเวอร์แค่ช่วยแนะนำให้รู้จักกัน แล้วข้อมูลดวลวิ่งตรงระหว่างเครื่อง เข้ารหัสด้วยกุญแจห้องที่อยู่หลัง # ซึ่งไม่ถูกส่งไปเซิร์ฟเวอร์)
4. โหมดไม่มีอินเทอร์เน็ต (Wi-Fi เดียวกัน): สแกน QR สองรอบ (ผู้สร้าง → ผู้เข้า → ผู้สร้าง) แลกข้อมูลเชื่อมต่อได้โดยไม่ใช้เซิร์ฟเวอร์เลย
5. ทั้งสองเครื่องรันเอนจินเดียวกันแล้วเทียบผลทุกเทิร์น (กันโกง) ตามเอกสารสถาปัตยกรรม
- ข้อจำกัด: เครือข่ายบางแห่ง (มือถือบางค่าย/องค์กร) เชื่อมตรงไม่ได้ ต้องมีเซิร์ฟเวอร์ส่งต่อ (TURN) ซึ่งมีค่าแบนด์วิดท์

### 5.4 ดวลออนไลน์ผ่านเซิร์ฟเวอร์
- เซิร์ฟเวอร์สร้างห้อง จับคู่ รันเอนจินเป็นกรรมการ ส่งให้แต่ละฝั่งเฉพาะข้อมูลที่ฝั่งนั้นมีสิทธิ์เห็น
- ใช้กับ: อารีน่าจัดอันดับ, ศึกกิลด์, ทีม 2v2, กิจกรรม, ห้องที่มีผู้ชม
- การ์ดตำนานขึ้นไป: ส่งใบรับรอง + ลายเซ็น เซิร์ฟเวอร์ตรวจในหน่วยความจำ ไม่บันทึกความเชื่อมโยงกับบัญชี

## 6. กิลด์ (เซิร์ฟเวอร์เท่านั้น)
- ข้อมูลกิลด์ สมาชิก ตำแหน่ง แชท คลังโกลด์กิลด์ ประกาศ ศึกกิลด์ อยู่บนเซิร์ฟเวอร์ทั้งหมด
- **ระบบฝึกของกิลด์**
  - ลานฝึก: สมาชิกท้าดวลกันเองแบบไม่เสียอันดับ ผู้นำ/ครูฝึกเข้าชมและคอมเมนต์ได้
  - ด่านฝึกกิลด์: หัวหน้ากิลด์ตั้ง AI บอส + กติกาพิเศษ (เช่น "คืนราหูนิรันดร์") ให้สมาชิกท้า มีตารางคะแนนในกิลด์
  - โจทย์ปริศนารายสัปดาห์: สถานการณ์กลางเกมที่ต้องชนะใน 1 เทิร์น
  - เด็คต้นแบบกิลด์: แชร์รายชื่อการ์ด (ไม่ใช่ตัวการ์ด) ให้สมาชิกคัดลอกไปจัดเอง
  - รางวัล: แต้มกิลด์ + โกลด์ ตามกิจกรรมฝึก (นับในเพดานรางวัลรายวัน)

## 7. AI คู่ต่อสู้ — ทำได้
| ระดับ | วิธีคิด |
| --- | --- |
| ง่าย | เลือก action ที่ถูกกติกาแบบสุ่มถ่วงน้ำหนัก |
| กลาง | ให้คะแนนสถานะกระดาน (ดวงชะตา, พลังบนสนาม, การ์ดในมือ) แล้วเลือกตาที่ดีที่สุด 1 ชั้น |
| ยาก | ค้นหาล่วงหน้า 2–3 ชั้น + รู้จักธาตุ ราหู ทวารบาล |
| ปรมาจารย์ | Monte Carlo Tree Search เดาไพ่ที่มองไม่เห็นจากการ์ดที่เปิดแล้ว (ไม่โกงดูไพ่ผู้เล่น) |
- **ฝึกส่วนตัว**: AI รันในเครื่อง เล่นออฟไลน์ได้ เลือกระดับ เลือกเด็ค AI (ทัพผี, ทัพเทพ, ทัพหิมพานต์, ทัพกรุงศรี) และโหมดสอนเล่น
- **ฝึกในกิลด์**: AI บอสที่หัวหน้าตั้งค่า ผลที่ให้รางวัลจะถูกเซิร์ฟเวอร์เล่นซ้ำจาก seed + บันทึก action เพื่อตรวจว่าไม่โกง ก่อนให้รางวัล
- AI ไม่เคยได้รับข้อมูลลับของผู้เล่น (ใช้กฎการมองเห็นเดียวกับผู้เล่นจริง)
